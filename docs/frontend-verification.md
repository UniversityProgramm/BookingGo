# Проверка фронтенда BookingGo

Проверено локально 15 ноября 2026 года.

- `go test ./...`: успешно. Включает регрессионные тесты реальных маршрутов выхода, обязательности TOTP при включённой 2FA и необязательности при выключенной.
- `npm run typecheck`, `npm test`, `npm run build`: успешно; 37 тестов фронтенда.
- `npm audit`: найдено 0 уязвимостей после обновления тестовых зависимостей.
- Docker Compose: образы Go и Nginx/React собраны, сервисы запущены. Проверены HTTP 200 для вложенного адреса SPA и HTTP 401 от API через Nginx без авторизации.
- На временной копии существующей схемы PostgreSQL с отдельными Redis и NATS прошёл 31 HTTP-запрос: регистрация и вход, доступ трёх ролей, создание и конфликт записи, отмена, запрет преждевременного завершения и завершение прошедшего визита, создание/редактирование/удаление клиента администратором, профиль, настройки и получение уведомлений, настройка/подтверждение/отключение TOTP, смена почты и пароля, выход и отказ при повторном использовании отозванного токена. Тестовые ресурсы удалены, исходные данные БД не менялись.
- Тесты компонентов дополнительно проверяют сохранение формы при конфликте, блокировку повторной отправки, ограничения маршрутов, HTTP 401/403, очистку кэша при завершении сессии, повтор после сетевой ошибки и оба формата уведомлений.

Визуальная проверка в браузере, в том числе мобильная ширина и навигация с клавиатуры в настоящем браузере, не выполнена: в сессии недоступен хост браузерной автоматизации. Адаптивные стили и семантические формы реализованы; тесты компонентов выполняются в jsdom.
